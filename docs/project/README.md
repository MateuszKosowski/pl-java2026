# Project Documentation

This folder contains the project report, diagrams and GUI screenshots used to document StegoCloud.

## Contents

| Path | Description |
|---|---|
| `project-report.pdf` | Final rendered project report |
| `project-report.tex` | LaTeX source for the report |
| `*.puml` | PlantUML source diagrams |
| `*.png` | Rendered diagrams and application screenshots |
| `render_puml.py` | Helper script for rendering PlantUML diagrams |

LaTeX build artifacts such as `.aux`, `.out`, `.toc` and `.synctex.gz` are intentionally not tracked.
